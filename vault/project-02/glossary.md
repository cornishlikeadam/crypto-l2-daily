# 🔤 Glossary: what the words mean

> [!tip] 👀 How to use this list
> Find the word in **bold**. Read the meaning next to it. Each meaning is **short and simple**.

## 🪙 Coins and crypto

| 🔤 Word | 💬 What it means |
|---|---|
| **Crypto** | Money that lives on computers, not in a bank. |
| **Blockchain** | A shared notebook. Lots of computers keep it. Nobody can secretly change it. |
| **Bitcoin (BTC)** ⚡ | The first and biggest crypto. |
| **Dogecoin (DOGE)** 🐕 | A crypto that started as a joke with a dog picture. Now it has a big community. |
| **Monero (XMR)** 🔒 | A crypto made to keep payments private. |
| **Litecoin (LTC)** 🪙 | A crypto like Bitcoin. It is faster and cheaper to send. |
| **Shill** | A person who hypes a coin to make money from it. The robot removes these posts. |

## 🧱 Add-ons (layer 2)

| 🔤 Word | 💬 What it means |
|---|---|
| **Layer 2 (L2)** | An extra layer on top of a coin. It makes the coin faster or cheaper. Or it lets the coin run apps. |
| **Lightning** ⚡ | A fast lane on top of Bitcoin (and Litecoin). It is for quick, cheap payments. |
| **Ark** | A newer Bitcoin add-on. It puts many small payments together to save fees. |
| **Sidechain** | A separate network linked to Bitcoin. It can try new features. |
| **FCMP++** | Monero's next privacy upgrade. It hides your coin among every coin on the chain. |
| **CARROT** | Monero's new address system. It comes with FCMP++. |
| **Stressnet / testnet** | A practice network. People test new software there with fake money. |
| **Hard fork** | A planned upgrade. Everyone who runs the network must install it. |
| **MWEB** | Litecoin's optional privacy feature. It can hide how much you send. |
| **DogeOS** | A layer 2 for Dogecoin. It lets people build apps. |

## 📡 The live numbers on the site

| 🔤 Word | 💬 What it means |
|---|---|
| **Fee (sat/vB)** ⛽ | The price to send Bitcoin. "sat/vB" means tiny bits of Bitcoin for each piece of data. |
| **Block** 🧱 | One page of the blockchain notebook. The number counts the pages. |
| **24h change** ▲▼ | How much the price went up ▲ or down ▼ in the last 24 hours. |

## 💻 Tools and web words

| 🔤 Word | 💬 What it means |
|---|---|
| **X** | The social media site. Its old name was Twitter. |
| **Post / handle** | A message on X / the account name, like `@monero`. |
| **API** | A door. One computer program uses it to ask another program for data. X charges money for its door. |
| **Scraper** | A program that reads a website like a person does. |
| **Cookie / login code** 🍪 | A small code your browser keeps. The website uses it to remember that you logged in. **Keep it secret.** |
| **Cron** ⏰ | The Mac's alarm clock for programs. It starts the robot at 6 PM. |
| **GitHub** | A website that keeps a backup of the code. |
| **Vercel** | The website host. It shows the videos. |
| **Obsidian** | The note app for this folder. |
| **Widget** 📱 | A small live card on your phone's Home Screen. |
| **Scriptable** | A free iPhone app. It runs small scripts, like our widget. |
| **ASD-STE100** ✍️ | A set of rules for simple, clear writing. These notes follow it. |
