# Glossary: what the words mean

| Word | What it means |
|---|---|
| **Crypto** | Money that lives on computers instead of in a bank. |
| **Blockchain** | A shared notebook that lots of computers keep, so nobody can secretly change it. |
| **Bitcoin (BTC)** | The first and biggest crypto. |
| **Dogecoin (DOGE)** | A crypto that started as a joke with a dog picture, and now has a big community. |
| **Monero (XMR)** | A crypto built to keep payments private. |
| **Litecoin (LTC)** | A crypto like Bitcoin, but faster and cheaper to send. |
| **Layer 2 (L2)** | An extra layer built on top of a coin to make it faster, cheaper, or able to run apps. |
| **Lightning** | A fast lane on top of Bitcoin (and Litecoin) for quick, cheap payments. |
| **Ark** | A newer Bitcoin add-on that bundles many small payments together to save fees. |
| **Sidechain** | A separate network linked to Bitcoin that can try new features. |
| **FCMP++** | Monero's next privacy upgrade. It hides your coin among every coin on the chain. |
| **CARROT** | Monero's new address system that comes with FCMP++. |
| **Stressnet / testnet** | A practice network where people test new software with fake money. |
| **Hard fork** | A planned upgrade that everyone running the network must install. |
| **MWEB** | Litecoin's optional privacy feature that can hide how much you send. |
| **DogeOS** | A layer 2 for Dogecoin that lets people build apps. |
| **X** | The social media site that used to be called Twitter. |
| **Post / handle** | A message on X / the account name, like `@monero`. |
| **API** | A door that lets one computer program ask another for data. X charges for its door. |
| **Scraper** | A program that reads a website the way a person would. |
| **Cookie / login code** | A small code your browser keeps so a website remembers you're logged in. Keep it secret. |
| **Cron** | The Mac's alarm clock for programs. It starts the robot at 6 PM. |
| **GitHub** | A website that keeps a backup of the code. |
| **Vercel** | The website host that shows the videos. |
| **Obsidian** | The note app this folder is made for. |
| **Shill** | Someone hyping a coin so they can make money from it. The robot throws these posts out. |
