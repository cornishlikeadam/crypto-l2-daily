# 🗺️ Crypto L2 Daily: the folder map

> [!abstract] 💵 What this is
> This folder explains a **robot**. Every day at **6 PM**, it makes a **70-second video** about crypto.
> Each file answers **one question**. Read them **in number order**.

| # | 📄 File | ❓ The question it answers |
|---|---|---|
| 01 | [[00-start-here]] | What does the robot make? What are the rules? |
| 02 | [[intent]] | What was my problem **before** AI? |
| 03 | [[01-collect-posts]] | Step 1: how does the robot get posts? |
| 04 | [[02-check-posts]] | Step 2: how does it remove the junk? |
| 05 | [[03-make-video]] | Step 3: how does it make the video? |
| 06 | [[04-human-check]] | Step 4: what do **I** check? |
