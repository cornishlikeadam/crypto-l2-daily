# Crypto L2 Daily: Project 2 packet

This folder explains a robot that makes a short video about crypto every day at 6 PM.
Read the files in this order. Each one is short.

| Order | File | What it tells you |

| 1 | [[00-start-here]] | What the robot makes, and the rules it follows |
